MARKDOWN 语法说明

发表于 2026-10-28 更新于 2026-10-29 分类于 其他
本博客支持的完整 Markdown 语法手册，涵盖标题、排版、列表、链接、图片、代码、表格、脚注、缩写、数学公式与 Next 标签插件，均附源码与渲染效果对照。

本页是本博客实际可用的 Markdown 语法手册。站点渲染器为 hexo-renderer-markdown-it，并启用了下标 / 上标、脚注、缩写、任务列表、定义列表、Emoji、扩展表格、按键、数学公式（MathJax3，服务端渲染为 SVG）等插件。每节均给出 Markdown 源码 与 渲染效果 对照。

一、标题

标题以 # 开头，# 的数量代表层级，共支持六级。建议从一级标题开始，并保持层级连续。

二、段落与换行

  • 段落：由一个或多个连续文本行组成，段落之间用空行分隔。
  • 换行：行尾添加两个空格后回车，或直接写一个空的 HTML 标签 <br>，即可在同一段落内强制换行。
  • 直接回车（不加两个空格）在多数情况下会被合并为一个空格。

渲染效果：

第二行

这是另一个段落。
它被强制换到了下一行。
